# 💀 Tema Kino TV - Día de Muertos

Celebra nuestras tradiciones con este espectacular tema oscuro para Kino TV, inspirado en los colores de las ofrendas y el papel picado.

## 🌼 Características
* **Fondo Cempasúchil:** Un inmersivo degradado que desciende desde la oscuridad absoluta hacia un hermoso tono naranja quemado.
* **Logotipo Calaverita:** Las letras de Kino TV fueron forjadas con vectores que convierten la letra "O" en una tradicional calaverita literaria, rodeada de pétalos de flor de cempasúchil.
* **Superficies Elegantes:** Fondos y paneles en color chocolate muy oscuro para mantener un aspecto moderno y misterioso.
* **Colores Ajustables:** Todos los colores que el usuario puede elegir (Rosa Mexicano, Morado, Azul Verde, Ladrillo, Mostaza) están calculados matemáticamente para leerse perfecto en Kino TV y dar el toque festivo final.

## 🕯️ Cómo instalar en Kino TV
1. Abre tu aplicación de **Kino TV**.
2. Ve a la sección de **Plugins**.
3. Añade un nuevo plugin y pega el enlace directo (Raw) del archivo `kino-plugin.json` de este repositorio.
4. Ve a **Ajustes > Apariencia** y selecciona **Calavera** para activarlo.
